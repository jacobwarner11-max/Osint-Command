# Upstream OSINT Tool Sources

OSINT Command Center launches external tools that must be installed separately. Verify installation instructions, licenses, provider requirements, and current usage guidance from each upstream project before use.

- Sherlock: https://github.com/sherlock-project/sherlock
- Maigret: https://github.com/soxoj/maigret
- Holehe: https://github.com/megadose/holehe
- PhoneInfoga: https://github.com/sundowndev/phoneinfoga
- theHarvester: https://github.com/laramies/theHarvester
- Subfinder: https://github.com/projectdiscovery/subfinder
- Amass: https://github.com/owasp-amass/amass

These projects are independent of OSINT Command Center and may change their command-line interfaces over time.
